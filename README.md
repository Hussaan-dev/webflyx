# Webflyx

Webflyx is a practice project created while completing the Git course on Boot.dev.

The repository was used to learn and practice common Git workflows, including:

* Repository initialization
* Staging and committing changes
* Branch creation and management
* Merging branches
* Resolving merge conflicts
* Working with remotes
* Pushing and pulling from GitHub

## Purpose

This project is intended as a learning exercise and serves as a record of Git concepts and workflows practiced throughout the course.

## Technologies

* Git
* GitHub

## Course

Created as part of the Boot.dev Git curriculum.
